# 操作台重构与界面优化

本版在 v3.1.4 原包上改进桌面操作台，沿用 Python/Tkinter 和原有 Windows 启动方式。

## 使用

将完整压缩包解压到新文件夹，双击 `启动操作台.bat`。需要已安装包含 tkinter 的 Python 3。
已有用户请先备份「设置」「数据库」和每日数据；升级时可仅覆盖「程序」目录，保留个人配置与历史记录。
新增的 `console_ui.py`、`console_config.py` 必须与 `tips_console.pyw` 一起更新。

## 本次改动

- 将字体、主题及主窗口布局抽到 `程序/console_ui.py`；后台任务与业务控制继续保留在操作台中。
- 将设置读取抽到不依赖图形界面的 `程序/console_config.py`，兼容 BOM 和旧版数字字符串。
- JSON 损坏、非对象设置、错误的字数上限、开关类型、时间格式分别回退默认值；读取时不覆盖用户设置文件，保留扩展字段。
- 顶部标题与工具栏分行，主操作和辅助操作分行，账号模式单独排列，减轻小窗口按钮拥挤。
- 统一深蓝标题、浅色背景、卡片边框及标签页间距，调整中文字体匹配，窗口初始大小根据屏幕尺寸选择。
- 支持 Alt+1～7 切换七个页面，Ctrl+Tab / Ctrl+Shift+Tab 切换相邻页面；F5 仍用于更新。
- 文件迁移逻辑识别新增模块，以兼容原有目录整理流程。

本次是操作台分层重构，尚未将所有采集器或后台流程拆成独立服务。数据来源、推单规则与算法未作调整。

## 验证

在项目根目录运行：

```bash
python -m unittest discover -s 验证 -v
```

原包 134 项测试通过。本次新增 5 项配置回归及 1 项真实 Tk 窗口测试，最终 140 项通过。
窗口测试在 Linux 虚拟显示器执行，检查七页切换、按钮回调、忙碌状态、阶段提示，以及 960×680 和 1180×900 下主要按钮可见性。
无图形桌面时，窗口测试会明确跳过；其余测试正常执行。测试使用临时副本，不触发自动采集。

Linux 截图使用测试机中文字体；Windows 会优先使用微软雅黑，实际外观略有差异。
外部站点实时采集、Windows 任务计划、浏览器图片导出尚未进行端到端验证。

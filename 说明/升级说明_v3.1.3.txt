v3.1.3 稳定性与缓存优化完整版
基于：v3.1.2 浏览器识别修复完整版

升级方法
关闭操作台及正在执行的任务，将完整包解压到原根目录覆盖同名程序文件，再重新启动操作台。
保留原「设置」「数据库」「每日数据」「推单」「报告」目录；不要删除数据库或历史记录。
本包只含程序、启动文件、说明和验证脚本，不包含运行生成的配置、数据或缓存。

本次修改
1. 数字彩、传统足彩开奖抓取或解析失败时，可从同一份旧 Excel 保留相应彩种/玩法的记录；继续标注「沿用旧数据」、原开奖日期和原抓取时间。
   不跨彩种、玩法混用，不将旧记录标为本次成功。合法空页面不会用开奖旧记录替代。
   不使用 --keep-older-draws 时，仍按昨日开奖日期筛选；旧文件不存在、旧文件已损坏、旧文件无该栏目时不能恢复。
2. 模型回测缓存签名改为实际内容摘要：包括开球时间、比分、联赛及规范化队名。
   同日同内容同参数复用；比分修正、联赛变化、队名映射变化会重新回测。
   老版缓存会在首次运行重新校验一次，参数择优仍按原周期执行；本次不调整模型阈值或推荐规则。
3. 模型检查结果、API 两队数据缓存、新浪页面缓存：同目录独立临时文件落盘后原子替换。
   替换失败保留原文件并清理临时文件；模型结果保存失败会在日志说明，避免误以为已经持久化。
4. 新浪与 API 缓存拒绝来自未来或时间字段非法的记录；数组等非法顶层结构视为未命中。
   正常的空数组 API 结果仍可在有效期内复用，不会因没有数据而连续重复请求。
5. 网络超时/最小间隔/进度保存间隔等浮点参数拒绝 NaN、正负无穷；操作台版本完整性检查同步更新。

保留功能
- v3.1.2 的浏览器自动识别、手动选择浏览器及图片导出功能。
- v3.1 的简短评论、每行一条、默认导出关键词与评论 TXT。
- v3.0.1 的队名简称对应、联赛消歧和一线队/梯队隔离规则。
